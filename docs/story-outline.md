# 森林秘境单章故事大纲

## 核心主题
- 这不是“一个人替全村受罚”的故事，而是“被集体逃避的责任，终究要被重新共同承担”的故事。
- 主角追进森林，不只是为了把姐姐救回来，也是为了保住两人共同的记忆与名字，不让旧债把亲密关系一点点抹掉。
- 森林索债并非单纯恶意报复，而是按旧约收回被村庄拿走却从未归还的东西：树脂、守林职责、以及对生命边界的敬畏。

## 角色关系
- 姐姐：多年暗中追查旧约真相，知道村庄并非无辜，也知道再拖下去只会让索债继续蔓延，因此选择先一步入林，想在黎明前抢先补上缺口。
- 主角：并非天然理解一切，但与姐姐共享最深的童年记忆，因此他是唯一既会冲进林里，又能在真相面前改变选择的人。
- 父辈与村庄：寒年里共同背弃守林旧约，拿走心树树脂、放弃轮值守林，并把后续代价层层转嫁给沉默者。
- 森林 / 心树：不是无差别吞噬，而是以旧约为尺度索还被拿走的东西；越被逃避，索债越会从“物”变成“名”和“记忆”。

## 12 场景大纲
1. 场景1：姐姐的房间  
   主角先与姐姐建立情感连接，明确她是有准备地离开，也为“为什么非追不可”打下私人理由。
2. 场景2：林缘石碑  
   正式进入森林，建立“是否被森林初步接受”的差异。
3. 场景3：红布猎道  
   让玩家意识到姐姐不是迷路，而是在主动引路。
4. 场景4：废猎人木屋  
   通过信、药袋、路线图补足父辈、村庄与姐姐之间的关系。
5. 场景5：回声岔谷  
   让“姐姐的呼喊”从表层求救变成真假辨认测试。
6. 场景6：镜湖  
   正面揭示村庄曾背弃旧约，姐姐此行是在替所有人补偿。
7. 场景7：失名林  
   强化兄妹共同记忆，让主角的动机从“救人”扩展到“守住彼此的过去”。
8. 场景8：黑暗沼泽  
   保留高危消耗节点，并让前面积累的信任/线索影响通过体验。
9. 场景9：断桥祭坛  
   白鹿与心种作为隐藏结局核心条件，测试主角是否愿意为其他生命停步。
10. 场景10：沉钟回廊  
    用钟声中的告白说明森林如何讨债、姐姐为何坚持要有人让索债停下。
11. 场景11：心树前庭  
    让姐姐真正说完来龙去脉，使最终选择有情感和逻辑支撑。
12. 场景12：心树空地  
    最终抉择落在“强行救回姐姐”与“共同修复旧约”之间。

## 结局逻辑
- `fail`：中途记忆耗尽，或最终修约时条件不足，说明主角还无法真正承接旧约。
- `victory`：主角救回姐姐，但旧债没有彻底结束；可由直接砍根，或修约条件只达成部分时触发。
- `hidden`：`trustForest === true && truthClueCount >= 5 && savedWhiteDeer === true && hasHeartSeed === true && memory > 0` 时触发，代表主角与姐姐一起完成真正修复。
